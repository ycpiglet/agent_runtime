## Blocking Finding

### W4B-601-001 — Host-template release wiring is absent (High)

The unit scope says to change “role-routing claim creation, live/template
release wiring,” and its target files include:

`src/agent_runtime/templates/project/scripts/task_claim_dispatcher.py`

Direct inspection at `08783fb` measured:

```json
{
  "template_role_routing_exists": false,
  "template_release_routing_hit_count": 0
}
```

Additionally:

- `git diff 766843e..08783fb --
  src/agent_runtime/templates/project/scripts/task_claim_dispatcher.py` is
  empty.
- `src/agent_runtime/templates/project/scripts/role_routing.py` does not exist.
- The template dispatcher contains no `role_routing` import,
  `route_review_pass` call, or `overlay` recursion guard.
- `tests/test_role_routing_wiring.py` invokes the root live dispatcher under
  `scripts/`; it does not execute an installed/generated host template.

Consequently, the passing focused suite proves the live checkout but cannot
prove the registered host-template scope. In a generated host, setting
`AR_ROLE_ROUTING=1` on ordinary worker release still creates no review overlay,
so the required “ordinary release creates one overlay” behavior is absent
rather than merely non-recursive.

The passing host lock check only proves that the fixture matches the unchanged
template. It is not evidence that the desired routing feature exists in that
template.
