## W4b Finding 1 — Strict Registry-Derived Role Authorization

The former line scanner was replaced by a bounded parser for the exact Runtime
registry subset. Authorization now requires all of the following before a role
ID is returned:

- a stable UTF-8 snapshot of at most 128 KiB from a regular, non-symlink file;
- the exact `agent-runtime-org-model/v1` schema and all five required
  top-level keys;
- only supported indentation levels and direct `teams`/`roles` list entries;
- complete team records (`id`, `display_name`) and complete role records
  (`id`, `tier`, `team`, `aliases`);
- canonical, unique team/role/tier identifiers and bounded, unique inline-list
  values;
- role references to registered tiers and teams; and
- no duplicate top-level keys, duplicate entry properties, duplicate IDs,
  trailing garbage, unsupported nesting, malformed scalar, or malformed list.

The file read retains the existing component-by-component `lstat()` checks and
adds final-node `O_NOFOLLOW` where supported, descriptor identity comparison,
pre/post size and modification-time comparison, and a strict byte bound.

Import-sentinel regressions prove that none of these inputs reaches Allimbot
construction:

```text

duplicate roles section
```

Positive regressions prove that a complete direct role entry is accepted and
that both the Runtime root registry and project-template registry conform.

## W4b Finding 2 — Managed Security-Gate Path and Content Integrity

The dispatcher no longer follows `Path.is_file()` through an unchecked parent.
Before claim persistence it now:

1. uses `lstat()` to require `scripts/` to be a real directory;
2. uses `lstat()` to require the final gate to be a bounded regular,
   non-symlink file;
3. compares parent and file identities before, during, and after the read;
4. requires the exact managed gate digest
   `a40384ca372d1c986538800687c8e339c45ed72bd3f167631be2f6e799ce32ce`;
5. rejects missing-after-presence, unreadable, oversized, drifted, or
   concurrently invalidated snapshots; and
6. executes the already verified source snapshot through a bounded Python
   bootstrap instead of reopening the path after verification.

This also closes the adjacent regular-file substitution case: a plain
`raise SystemExit(0)` file is not accepted merely because it is regular.
