## Blocking Finding

### Malformed required security metadata is normalized into valid values

`src/agent_runtime/security_service.py` currently parses every frontmatter
scalar as follows:

```python
normalized = value.strip().strip("\"'")
if normalized.lower() == "true":
    return True
if normalized.lower() == "false":
    return False
return normalized
```

This does not parse or reject quote syntax. It strips any leading or trailing
quote characters independently, so an unterminated quoted value becomes the
same trusted value as a valid plain scalar.

The independent temporary-host probe used:

```text
host configuration:
  schema: agent-runtime-config/v2
  profiles: [security-service]
  otherwise valid documented v2 sync fields

installed boundary:
  exact managed scripts/security_service_gate.py
  exact managed SECURITY-SERVICE-POLICY.json

canonical unit identity:
  TASK-AR-648 / UNIT-TASK-AR-648-001

registered target:
  .env.production

required metadata:
  risk_tier: "high
  security_sensitive: "true
  approval_required: "true
  escalation_triggers: [security]

required section:
  ## Security Controls
```

All three quoted scalar values are unterminated. The security policy requires
`risk_tier` high or critical, boolean `security_sensitive: true`, boolean
`approval_required: true`, the `security` escalation trigger, and the
`Security Controls` section for this target.

Observed result:

```text
dispatcher_returncode=0
persisted_claims=1
```

This is a material fail-open at the exact guardrail introduced by this unit.
It is not a display-only or post-claim diagnostic discrepancy: the malformed
document passes the verified managed gate and reaches claim persistence.

The same decision source is also opened with an unbounded
`Path.read_text()` after a separate component `lstat()` walk. That does not
provide the bounded, single stable snapshot used by the hardened registry,
gate, and profile-state readers.

Required rework:

1. define and enforce a fixed supported scalar grammar for every
   security-decision field before trusting any unit metadata;
2. reject unterminated quotes, tags, anchors, aliases, block scalars, and
   unsupported container syntax rather than stripping indicators;
3. require actual boolean literals for `security_sensitive` and
   `approval_required`; a quoted string or malformed quoted scalar must not
   satisfy a boolean requirement;
4. validate the whole supported frontmatter subset before any field is used
   for authorization, preserving duplicate-field and canonical-identity
   rejection;
5. read the canonical unit document through a bounded, stable,
   non-symlink snapshot at the claim gate; and
6. add failure-first dispatcher regressions proving the exact malformed
   `.env.production` fixture returns 1 and persists zero claims before
   creating another W4a.
