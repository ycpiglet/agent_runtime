# TASK-AR-608 Independent W4b Verification

## Verdict

**REJECT.** The implementation preserves `#` inside the registered quoted-scalar cases, but it also changes the established comment boundary for quoted-looking fragments that occur after plain-scalar content. This violates the acceptance requirement that unquoted comments retain their current behavior.

This report is deliberately scoped to implementation `871b6b9ed863647321129319ff37fac4e0473acc` and W4a HEAD `1c9ebc1c9b0841c8d64de3ed3b6f3b8ab4aad7e7`. Later remediation commits are not evaluated here.

## Blocking finding

### P1 — Whitespace inside a plain scalar incorrectly opens quote state

`strip_comment()` opens quote state when a quote follows arbitrary whitespace. Once plain scalar content has already started, that quote is not a scalar-opening delimiter. Treating it as one suppresses a later `#` that the previous implementation stripped as a comment.

Exact-blob probes against failure-first baseline `45085b33e0e29c48485edbc322b23026d0023c95` and verified HEAD `1c9ebc1c9b0841c8d64de3ed3b6f3b8ab4aad7e7` reproduced four compatibility regressions:

| Input | Baseline result | Verified implementation result | Compatibility |
|---|---|---|---|
| `plain 'PR #167' # outside` | `plain 'PR ` | `plain 'PR #167' ` | Fail |
| `plain \"PR #167\" # outside` | `plain \"PR ` | `plain \"PR #167\" ` | Fail |
| `owner ' fragment # outside` | `owner ' fragment ` | `owner ' fragment # outside` | Fail |
| `summary: plain \"unterminated # outside` | `summary: plain \"unterminated ` | full input retained | Fail |

Compatibility result: **0/4**. The defect is present identically in the live and template copies.

Required remediation: track whether parsing is at a scalar or flow-item start versus already inside plain content. A quote may open quoted state only at the former boundary, not merely after whitespace. Add these adversarial cases as regressions while preserving the registered positive cases. This remains a lexical fix and does not require a YAML dependency or broader parser expansion.
