## Contract Proof

- New routine task/unit registration defaults to `worker_low`; missing
  escalation triggers remain empty. Explicit `ambiguity`, `data_integrity`,
  `high_risk`, `security`, `cross_cutting`, `external_effect`, or
  `repeated_failure` escalates worker routes to `planner_high`.
- Claim creation records requested and selected tiers, routing status, reason,
  registered/unknown signals, and an unverified actual model rather than
  manufacturing execution evidence.
- Provider-neutral PM tiers are stable. Claude compatibility aliases remain
  supported, while provider resolution records provider, execution surface,
  resolved model/source, reasoning intent, equivalence, application state, and
  economic eligibility.
- The new read-only `explorer` and precise `implementer` roles default to
  `worker_low`; reviewer, strategist, auditor, and skeptic retain stronger
  role-appropriate defaults.
- Lookup-only generic/native dispatch requires
  `attempted_insufficient` with bounded evidence. A
  `completed_sufficient` preflight returns without a model call or packet
  write.
- Native Codex packets advertise capability `native_subagent_spawn`, current
  tool hint `collaboration.spawn_agent`, and exact task name, prompt, model, and
  reasoning arguments. Repository Python remains an audit bridge, not a second
  executor.
- Generic, native, provider-worker, and auto-dispatch records share dispatch
  correlation, requested/selected/resolved routing, application/equivalence
  state, deterministic-preflight state, model/usage availability, local
  latency, and billed-cost availability.
- Missing model, tokens, and billed cost remain `unverified` or `unavailable`.
  Request configuration is never copied into completion observations.
- `eval_harness` reports `token_delta` only for an applied, observed, effective
  model change with positive usage and a comparable baseline. It reports
  `monetary_delta` only from actual and baseline billed costs in the same
  currency. The legacy `cost_delta` key is an explicitly deprecated,
  non-monetary token alias.
- Doctor loads only the host routing module, performs no live probe, exposes
  four machine-readable matrices, and warns on equivalent mappings without
  printing provider credentials.
