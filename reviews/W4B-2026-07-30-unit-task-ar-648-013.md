The contract uses schema v2 and an explicit, sorted list of 84 safe relative
`.py`/`.cmd` paths.  It is neither a count nor a dynamically calculated
baseline.  The exact product gate returned:

```json
{
  "expected_common": 84,
  "current_common": 84,
  "identical": 81,
  "intentional": 3,
  "findings": []

```

The intentional divergent subset is exactly `compound_record.py`,
`owner_governance_gate.py`, and `stop_hook_owner_governance.py`.  Each belongs
to the expected inventory, has a nonempty bounded reason, and pins both the
source and template SHA-256.  The other 81 paths are byte-identical.

Static and executable review of `analyze()` confirms the required separation:

- every expected path absent from source returns
  `mirror:expected-source-missing:<path>`;
- every expected path absent from template returns
  `mirror:expected-template-missing:<path>` even after it leaves the current
  intersection;
- a new actual common path returns `mirror:unexpected-common:<path>`;
- one-sided assets outside the expected list are deliberately allowed.

The focused suite independently executed these cases: missing source, missing
template, formerly-common deletion, unexpected common addition, invalid list,
duplicate, unsafe/non-string and unsorted inventory, exception outside the
inventory, digest mismatch, stale exception, and duplicate JSON key.  The
gate's duplicate-key JSON loader, safe path validation, schema checks, and
invalid JSON paths are fail-closed.  There is no wildcard, prefix, or
count-only bypass.
