## Explicit Commit Transaction Contract

`claim_guard.py` creates a 32-hex nonce and a private record beneath the
repository Git path, then passes
`AGENT_RUNTIME_CLAIM_COMMIT_TRANSACTION` only in the `git commit` child
environment. The marker binds:

- schema;
- exact resolved Runtime root;
- exact claim JSON paths;
- nonce and private record;
- live owner PID;
- starting `HEAD`.

The gate additionally requires `scm_commit/true` metadata and equality between
the indexed and working-tree blobs. Missing, malformed, ambient, wrong-root,
wrong-path, dead-owner, wrong-`HEAD`, unstaged, working-tree-mode, and
index-mismatched cases do not receive the exception. The private record is
removed in `finally`, including hook failure. The existing failing-hook
regression still leaves the three artifacts staged and the ordinary gate still
blocks with `task-claim:authorized-commit-not-persisted`.
