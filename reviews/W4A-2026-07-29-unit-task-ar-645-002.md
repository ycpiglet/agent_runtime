The implementation replaces the old Scribe line-count heuristic with a generic,
bounded Markdown/JSON state-adapter contract. It produces an explicitly
generated, digest-bound projection only on request; Doctor, SessionStart, and
ordinary Scribe checks remain read-only. Canonical host status and backlog
sources remain host-owned.

## W4a Repairs Before the Fixed Head

W4a tightened two boundaries before fixing the implementation head:

1. arbitrary configured state sources must resolve to `host_owned` or
   `seed_once`, while the default or custom projection must resolve to
   `generated`; a custom projection must also be distinct from every source;
2. a credential-shaped test value rejected by the public sanitizer was replaced
   with a non-credential placeholder while preserving field-name and private
   content redaction coverage.

No consumer repository, live host status file, version, tag, publication,
release, or deployment was changed.

## Contract Proof

- `host.state_adapters` accepts at most eight safe relative Markdown/JSON
  sources; missing configured sources and unavailable conventional fallbacks
  are explicit and never collapse to `hot=0`.
- Conventional fallback order is
  `agents/lead_engineer/STATUS.md`, `STATUS.md`, `BACKLOG.md`,
  `docs/PROJECT_STATUS.md`, `docs/PROJECT_STATUS.ko.md`, then
  `PROJECT_STATUS.md`.
- Markdown parsing preserves nearest headings and checklist state. JSON parsing
  accepts only bounded top-level work lists and projects only
  `id`/`name`/`title`/`summary`/`status`.
- Projection selection is capped at ten items, headings at 160 characters,
  items at 240 characters, sources at eight, and the serialized artifact at
  32 KiB.
- Credentials, environment assignments, prompt/transcript content,
  private-key markers, and arbitrary JSON fields are omitted or redacted.
- Projection freshness binds the exact source set, relative paths, and SHA-256
  digests. The write path uses an atomic same-directory replacement and rejects
  traversal and symlink escape.
- State thresholds are `ok <= 12`, `due = 13..15`, and `overdue >= 16`.
  Substantial closeout blocks only for a present overdue source with a missing
  or stale projection; `due`, unavailable optional input, and mini work remain
  advisory.
- Root/template copies of `scribe_due.py`, `closure_gate.py`, and
  `session_start_hook.py` are byte-identical.
- Synthetic Agent Runtime, Bean Wiki, Allimbot, Autofolio, and generic JSON
  fixtures all use the same adapter API and exercise their expected state
  shapes.

## Residual Boundaries

  for canonical host state or a product-specific semantic parser.
- Digest freshness detects source-content changes; it does not interpret whether
  two differently worded items are semantically equivalent.
- The release version remains `0.7.0`. Version bumping, tagging, packaging, and
  publication are reserved for TASK-AR-651 after the remaining v0.8 units and
  pilots complete.
