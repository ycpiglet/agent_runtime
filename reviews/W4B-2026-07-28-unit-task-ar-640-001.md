## Blocking findings

### 1. v1 `sync.unmanaged` is no longer backward-compatible

The former v1 reader converted backslashes to POSIX separators. The required
legacy fixture:

```yaml
project: demo
sync:
  mode: check-diff-apply
  allow_silent_overwrite: false
  unmanaged:
    - agents\\host\\NOTES.md
```

now raises:

```text
ValueError: ... sync.unmanaged is not a safe repo-relative POSIX path:
'agents\\host\\NOTES.md'
```

`load_config()` applies `_normal_path()` to v1 `sync.unmanaged`
([config.py](/home/keti-itp-01/ycpiglet/agent_runtime/.worktrees/TASK-AR-640/src/agent_runtime/config.py:320)), whereas the prior implementation performed
`replace("\\", "/")`. W0 explicitly requires byte-compatible v1
`unmanaged_paths`; preserve that legacy normalization before only projecting it
as `host_owned`.

### 2. v2 parser silently accepts malformed or misspelled declarations

These validly parse and load rather than producing a blocker:

```yaml
profilse: nope                 # unknown top-level key
sync: { typo: nope }           # represented in bounded block form during probe
upstream: { pakcage: nope }
host: { role_overly: agents/host/X.yml }
```

The bounded parser also accepts an entire document shifted one indentation
level. This violates the explicit-schema / visible-malformed-config boundary:
typos must not silently disappear. `load_config()` needs per-schema allowed-key
validation for root, `sync`, `upstream`, and `host`, and `_parse_document()`
must require a zero-indented top-level mapping.

### 3. Path and reserved-namespace validation has bypasses

`ownership.managed: [C:/temp/x]` is accepted even though a Windows-drive path
is absolute. In addition, both `ownership.managed: [agents/host]` and
`ownership.generated: [agents/host]` are accepted. The current test only
checks the child spelling because the guard is
`item.startswith("agents/host/")`
([config.py](/home/keti-itp-01/ycpiglet/agent_runtime/.worktrees/TASK-AR-640/src/agent_runtime/config.py:244)).

Reject drive-qualified paths and treat both `agents/host` and every descendant
as host-owned-only. Add focused regression coverage for all ownership modes.

### 4. Host-context scalar contract is coerced instead of validated

An invalid mapping under `purpose`, a list under `domain`, and a nested mapping
as a `role_mapping` value all load successfully, coercing structures into Python
string representations. The coercions occur at
[config.py](/home/keti-itp-01/ycpiglet/agent_runtime/.worktrees/TASK-AR-640/src/agent_runtime/config.py:281).
The documented bounded shape is scalar `purpose`/`domain` and a scalar-to-scalar
`role_mapping`; reject non-string values before projection.

`/tmp/.../host/agent_runtime.yml`, not the required host-relative POSIX
`agent_runtime.yml`. Both valid and invalid branches stringify absolute paths
([doctor.py](/home/keti-itp-01/ycpiglet/agent_runtime/.worktrees/TASK-AR-640/src/agent_runtime/doctor.py:731),
[doctor.py](/home/keti-itp-01/ycpiglet/agent_runtime/.worktrees/TASK-AR-640/src/agent_runtime/doctor.py:737)).
