# Vision - MVP Client Overlay

## Purpose

Launch a domain-specific MVP with the shared agent_runtime team while keeping the runtime core unchanged.

## Product Goal

- Provide a project-specific agent team that understands the client's idea, operating context, roadmap, and decision chain from overlay files.
- Preserve shared runtime skills, hooks, and scripts unless the release gate approves a reusable runtime change.

## Non-Goals

- Forking common agent skills for client-specific behavior.
- Editing runtime core scripts to encode one project's private context.
